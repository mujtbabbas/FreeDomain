# Reader's Guide — FreeDomain

## What this project is

FreeDomain is **DigitalPlat FreeDomain's public information and learning
repository**: free domain registration plus practical DNS learning resources
for everyone. You register a domain on the DigitalPlat dashboard, connect your
preferred DNS provider through custom nameservers, and use the guides here to
take a project from registration to deployment. The application source code
itself lives in a separate repository (DigitalPlatDev/Domain-OSS); this repo
holds the docs, guides and community files.

Available free extensions listed in the README: **.DPDNS.ORG**, **.US.KG**,
**.QZZ.IO**, **.XX.KG** and **.QD.JE**.

## How the content is organised

- [`README.md`](README.md) — the front door: what FreeDomain is, the available
  extensions, how to claim a domain, the FAQ pointer, community links and an
  abuse-reporting note.
- [`LEARN.md`](LEARN.md) — the book-style learning path, from FreeDomain setup
  through general DNS, websites, email, operations and advanced topics.
- `documents/` — the detailed documentation tree:
  - `documents/tutorial/` — the step-by-step registration tutorial
    (start at `documents/tutorial/index.md`).
  - `documents/domains/` — domain reference material, including the FAQ
    (`documents/domains/faq.md`).
- `assets/` — images used by the docs, including the project logo.
- Community and project files: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`,
  `SECURITY.md`, and `LICENSE` (AGPL-3.0).

## How to use it

1. **Just want a domain?** Follow the README's "Ready to Claim Your Free
   Domain?" section to the DigitalPlat dashboard, then work through
   `documents/tutorial/index.md`.
2. **Want to actually understand DNS?** Read `LEARN.md` end to end — it is
   written as a guided path, not a reference dump.
3. **Stuck?** Check `documents/domains/faq.md` first, then ask in the
   community channels linked from the README.
